[[[ START FILE: README.md ]]] KENZEN Cockpit for Perchance (Android & PWA) A mobile-first Android port and evolution of Tomohito Fujikawa's (tmhtdst0508-ux) Windows-desktop KENZEN-SeaArt-Helper, optimized specifically for Perchance.org image generators including Mack's Place (mack-mcgenerator), AI Real Revolution, Qinegen, and The Imaginarium. Key Features 1. Natural Language Flux Prose Synthesizer Transforms tag soup into descriptive, natural English sentences that Flux.1-schnell and Chroma obey cleanly. 2. 41-Category Precedence Matrix Complete bilingual (Japanese / English) taxonomy organized in perceptual order. 3. Mack's 8-Box Architecture Support Can export directly into Mack's Place slots ([Style], [Subject], [Fashion], [Scene], [Pose], [Negative]). 4. Touch Ergonomics Tap to toggle with commas; touch-and-hold to open the bottom-sheet inspector for weights, connectors, and alternations. 5. Zero Server Dependency Pure client-side logic powered by IndexedDB. Runs entirely offline once installed. Build with GitHub Actions Push this repository to GitHub. The included workflow .github/workflows/build-apk.yml will: 1. Set up Node 20, Java 17, and the Android SDK. 2. Generate all required launcher icons. 3. Compile a native debug APK using Capacitor and Gradle. 4. Upload kenzen-cockpit-perchance.apk as a downloadable GitHub Actions artifact.
